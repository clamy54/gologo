Installation

Télécharger et installer GoLogo sous Windows, Linux et macOS.

GoLogo est distribué sous forme de binaires prêts à l'emploi pour Windows, Linux et macOS. Ils sont disponibles dans la section Releases du dépôt GitHub. Choisissez le fichier correspondant à votre système, puis suivez la procédure ci-dessous.

Binaires non signés. Sous Windows et macOS, les exécutables ne sont pas signés numériquement. Au premier lancement, le système peut afficher un avertissement de sécurité : c'est normal. La marche à suivre est décrite plus bas, dans Avertissements de sécurité.

Windows

Un programme d'installation classique est fourni.

  1. Depuis la page Releases, téléchargez le fichier d'installation Windows (GoLogo-Setup-x.x.exe).
  2. Double-cliquez dessus et suivez l'assistant (choix du dossier, raccourci sur le bureau en option).
  3. GoLogo apparaît ensuite dans le menu Démarrer. Les programmes d'exemple sont installés à côté de l'exécutable.

Au tout premier lancement, voir l'avertissement Windows SmartScreen plus bas.

Linux (Debian / Ubuntu)

Un paquet .deb est fourni pour les distributions à base de Debian (Debian, Ubuntu, Linux Mint...), architecture 64 bits (amd64).

  1. Depuis la page Releases, téléchargez le paquet (gologo_x.x_amd64.deb).
  2. Installez-le avec apt, qui gère automatiquement les dépendances : 
    sudo apt install ./gologo_x.x_amd64.deb
  3. Lancez gologo depuis un terminal ou depuis le menu des applications. Les programmes d'exemple sont installés dans /usr/share/doc/gologo/examples.

Le paquet Linux n'est pas concerné par les avertissements de signature : il s'installe normalement.

macOS (Apple Silicon)

Apple Silicon uniquement. La version macOS fonctionne seulement sur les Mac à puce Apple Silicon (M1 et ultérieurs : M1, M2, M3...). Les Mac à processeur Intel ne sont pas pris en charge.
  1. Depuis la page Releases, téléchargez l'archive macOS et décompressez-la.
  2. Glissez GoLogo.app dans votre dossier Applications.
  3. Au premier lancement, voir l'avertissement macOS Gatekeeper plus bas.

Avertissements de sécurité

GoLogo est un logiciel libre et gratuit. Les exécutables ne sont pas signés numériquement (les certificats de signature de code sont coûteux et ne se justifient pas pour une application gratuite). De ce fait, votre système d'exploitation peut afficher un avertissement de sécurité au premier lancement. C'est normal et attendu : voici comment procéder sur chaque plateforme.

Windows

Au premier lancement de GoLogo, Windows SmartScreen peut afficher une fenêtre bleue indiquant « Windows a protégé votre ordinateur ».

  1. Cliquez sur Informations complémentaires (le lien sous le texte d'avertissement).
  2. Cliquez sur Exécuter quand même.

Cet avertissement n'apparaît qu'une fois. Ensuite, Windows retient votre choix et ne redemande plus.

macOS

macOS Gatekeeper bloque par défaut les applications de développeurs non identifiés. À la première tentative d'ouverture de GoLogo, un message indique que l'application « ne peut pas être ouverte car elle provient d'un développeur non identifié » (ou « macOS ne peut pas vérifier l'absence de logiciels malveillants »).

  1. Fermez la boîte de dialogue d'avertissement.
  2. Ouvrez Réglages Système (menu Pomme > Réglages Système).
  3. Allez dans Confidentialité et sécurité.
  4. Faites défiler vers le bas : un message indique que GoLogo a été bloqué. Cliquez sur Ouvrir quand même.
  5. Saisissez votre mot de passe ou utilisez Touch ID pour confirmer.
  6. Une nouvelle fenêtre apparaît : cliquez sur Ouvrir.

Cette autorisation n'est à faire qu'une seule fois. Ensuite, macOS ouvre GoLogo normalement.
